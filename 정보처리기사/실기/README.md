## ✏️ 작성 시 주의사항

### SQL 작성 주의사항
1. **세미콜론(;)** 빠뜨리지 않기
2. **키워드 철자** 정확히 (SELECT, FROM, WHERE 등)
3. **따옴표** 구분 (' vs ")
4. **별칭** 사용 시 AS 생략 가능하지만 명확히
5. **괄호** 잘 닫기

### 용어 작성 주의사항
1. **영문/한글** 명시된 대로 작성
2. **대소문자** 구분 (약어는 대부분 대문자)
3. **띄어쓰기** 주의
4. **약어 풀이** 시 정확히

## 📖 필수 암기 항목

### SQL 필수 문법
```sql
-- SELECT 기본
SELECT 컬럼명 FROM 테이블명 WHERE 조건;

-- JOIN
SELECT * FROM A INNER JOIN B ON A.id = B.id;

-- GROUP BY
SELECT 컬럼, COUNT(*) FROM 테이블 GROUP BY 컬럼 HAVING 조건;

-- 서브쿼리
SELECT * FROM 테이블 WHERE 컬럼 IN (SELECT 컬럼 FROM 테이블2);
```

### 관계 대수 기호
- σ (시그마): Select (선택)
- π (파이): Project (투영)
- ⋈ (보타이): Join (조인)
- ÷ (나누기): Division (나눗셈)
- ∪ (합집합): Union
- ∩ (교집합): Intersection
- - (차집합): Difference

### C 언어 자주 나오는 코드
```c
// 포인터
int *p, a = 10;
p = &a;
printf("%d", *p);  // 10

// 배열
int arr[3] = {1, 2, 3};
printf("%d", arr[0]);  // 1

// 문자열
char str[] = "Hello";
printf("%s", str);  // Hello

// 반복문
for(int i = 0; i < 5; i++) {
    printf("%d ", i);  // 0 1 2 3 4
}
```
