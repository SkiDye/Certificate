# 신기술 용어집

## 📌 클라우드 컴퓨팅

### 서비스 모델
- **IaaS** (Infrastructure as a Service): 인프라 제공 (AWS EC2, Azure VM)
- **PaaS** (Platform as a Service): 플랫폼 제공 (Heroku, Google App Engine)
- **SaaS** (Software as a Service): 소프트웨어 제공 (Gmail, Office 365)

### 배포 모델
- **Public Cloud**: 공용 클라우드
- **Private Cloud**: 사설 클라우드
- **Hybrid Cloud**: 혼합 클라우드
- **Community Cloud**: 커뮤니티 클라우드

### 주요 기술
- **VM** (Virtual Machine): 가상 머신
- **Container**: 컨테이너 (Docker)
- **Kubernetes**: 컨테이너 오케스트레이션
- **Serverless**: 서버리스 (AWS Lambda)

## 📌 인공지능 (AI)

### 기계학습 (Machine Learning)
- **지도 학습** (Supervised Learning): 레이블 있는 데이터로 학습
- **비지도 학습** (Unsupervised Learning): 레이블 없는 데이터로 학습
- **강화 학습** (Reinforcement Learning): 보상을 통한 학습

### 딥러닝 (Deep Learning)
- **CNN** (Convolutional Neural Network): 합성곱 신경망 (이미지 인식)
- **RNN** (Recurrent Neural Network): 순환 신경망 (시계열 데이터)
- **GAN** (Generative Adversarial Network): 생성적 적대 신경망

### AI 기술
- **NLP** (Natural Language Processing): 자연어 처리
- **Computer Vision**: 컴퓨터 비전
- **Chatbot**: 챗봇
- **ChatGPT**: 대화형 AI

## 📌 빅데이터

### 빅데이터 특징 (3V → 5V)
- **Volume**: 데이터 크기
- **Velocity**: 데이터 속도
- **Variety**: 데이터 다양성
- **Veracity**: 데이터 정확성
- **Value**: 데이터 가치

### 빅데이터 기술
- **Hadoop**: 분산 파일 시스템
- **HDFS** (Hadoop Distributed File System): 하둡 분산 파일 시스템
- **MapReduce**: 분산 처리 프레임워크
- **Spark**: 빠른 데이터 처리
- **NoSQL**: 비관계형 데이터베이스 (MongoDB, Redis, Cassandra)

### 데이터 분석
- **Data Mining**: 데이터 마이닝
- **Data Lake**: 데이터 레이크
- **Data Warehouse**: 데이터 웨어하우스
- **ETL** (Extract, Transform, Load): 추출, 변환, 적재

## 📌 블록체인

### 기본 개념
- **Blockchain**: 분산 원장 기술
- **Bitcoin**: 비트코인 (암호화폐)
- **Cryptocurrency**: 암호화폐
- **Mining**: 채굴
- **Smart Contract**: 스마트 계약

### 합의 알고리즘
- **PoW** (Proof of Work): 작업 증명
- **PoS** (Proof of Stake): 지분 증명
- **DPoS** (Delegated Proof of Stake): 위임 지분 증명

### 블록체인 플랫폼
- **Ethereum**: 이더리움
- **Hyperledger**: 하이퍼레저
- **NFT** (Non-Fungible Token): 대체 불가능 토큰

## 📌 IoT (사물인터넷)

### 기본 개념
- **IoT** (Internet of Things): 사물인터넷
- **Sensor**: 센서
- **Actuator**: 액츄에이터
- **M2M** (Machine to Machine): 기기 간 통신

### IoT 프로토콜
- **MQTT**: 경량 메시징 프로토콜
- **CoAP**: 제한된 환경을 위한 프로토콜
- **LoRa**: 장거리 저전력 통신
- **Zigbee**: 저전력 무선 통신

### IoT 플랫폼
- **Edge Computing**: 엣지 컴퓨팅
- **Fog Computing**: 포그 컴퓨팅

## 📌 보안

### 최신 보안 기술
- **Zero Trust**: 제로 트러스트
- **SIEM** (Security Information and Event Management): 보안 정보 및 이벤트 관리
- **EDR** (Endpoint Detection and Response): 엔드포인트 탐지 및 대응
- **XDR** (Extended Detection and Response): 확장 탐지 및 대응

### 암호화폐/보안
- **Ransomware**: 랜섬웨어
- **APT** (Advanced Persistent Threat): 지능형 지속 위협
- **Zero-Day**: 제로데이 취약점

## 📌 소프트웨어 개발

### DevOps
- **DevOps**: 개발(Dev) + 운영(Ops)
- **CI/CD** (Continuous Integration/Continuous Deployment): 지속적 통합/배포
- **Jenkins**: CI/CD 도구
- **Git**: 버전 관리 시스템
- **Docker**: 컨테이너 플랫폼

### 아키텍처
- **MSA** (Microservices Architecture): 마이크로서비스 아키텍처
- **API Gateway**: API 게이트웨이
- **Service Mesh**: 서비스 메시

### 개발 방법론
- **Agile**: 애자일
- **Scrum**: 스크럼
- **Kanban**: 칸반
- **TDD** (Test-Driven Development): 테스트 주도 개발
- **DDD** (Domain-Driven Design): 도메인 주도 설계

## 📌 웹/모바일

### 웹 기술
- **SPA** (Single Page Application): 단일 페이지 애플리케이션
- **PWA** (Progressive Web App): 프로그레시브 웹 앱
- **SSR** (Server-Side Rendering): 서버 사이드 렌더링
- **CSR** (Client-Side Rendering): 클라이언트 사이드 렌더링

### API
- **REST API**: Representational State Transfer API
- **GraphQL**: 쿼리 언어
- **gRPC**: 고성능 RPC 프레임워크
- **Webhook**: 웹훅

### 프론트엔드
- **React**: 리액트 (프론트엔드 라이브러리)
- **Vue.js**: 뷰 (프론트엔드 프레임워크)
- **Angular**: 앵귤러 (프론트엔드 프레임워크)

## 📌 데이터베이스

### NoSQL 종류
- **Key-Value**: Redis, DynamoDB
- **Document**: MongoDB, CouchDB
- **Column-Family**: Cassandra, HBase
- **Graph**: Neo4j

### 데이터베이스 기술
- **Sharding**: 샤딩 (수평 분할)
- **Replication**: 복제
- **Partitioning**: 파티셔닝
- **Indexing**: 인덱싱

## 📌 네트워크

### 최신 네트워크 기술
- **5G**: 5세대 이동통신
- **SDN** (Software-Defined Networking): 소프트웨어 정의 네트워킹
- **NFV** (Network Function Virtualization): 네트워크 기능 가상화
- **CDN** (Content Delivery Network): 콘텐츠 전송 네트워크

### 네트워크 프로토콜
- **HTTP/2**: HTTP 버전 2
- **HTTP/3**: HTTP 버전 3 (QUIC 기반)
- **WebSocket**: 웹소켓 (양방향 통신)

## 📌 자주 출제되는 약어

### A-C
- **AI** (Artificial Intelligence): 인공지능
- **API** (Application Programming Interface): 응용 프로그램 프로그래밍 인터페이스
- **AR** (Augmented Reality): 증강현실
- **AWS** (Amazon Web Services): 아마존 웹 서비스
- **BYOD** (Bring Your Own Device): 개인 기기 활용

### D-F
- **DDoS** (Distributed Denial of Service): 분산 서비스 거부
- **DNS** (Domain Name System): 도메인 네임 시스템
- **FTP** (File Transfer Protocol): 파일 전송 프로토콜

### G-I
- **GPU** (Graphics Processing Unit): 그래픽 처리 장치
- **HTML** (HyperText Markup Language): 하이퍼텍스트 마크업 언어
- **HTTPS** (HTTP Secure): 보안 HTTP
- **IDE** (Integrated Development Environment): 통합 개발 환경

### J-M
- **JSON** (JavaScript Object Notation): 자바스크립트 객체 표기법
- **JWT** (JSON Web Token): JSON 웹 토큰
- **ML** (Machine Learning): 기계학습
- **MVC** (Model-View-Controller): 모델-뷰-컨트롤러

### N-R
- **NAS** (Network Attached Storage): 네트워크 결합 스토리지
- **OAuth**: 개방형 인증
- **ORM** (Object-Relational Mapping): 객체 관계 매핑
- **REST** (Representational State Transfer): 표현 상태 전이

### S-Z
- **SDK** (Software Development Kit): 소프트웨어 개발 키트
- **SQL** (Structured Query Language): 구조적 질의 언어
- **SSL/TLS**: 보안 소켓 계층/전송 계층 보안
- **UI/UX**: 사용자 인터페이스/사용자 경험
- **VPN** (Virtual Private Network): 가상 사설망
- **VR** (Virtual Reality): 가상현실
- **XML** (eXtensible Markup Language): 확장 마크업 언어
