# 관계 대수 (Relational Algebra)

## 📌 관계 대수란?
관계형 데이터베이스에서 원하는 정보를 얻기 위해 릴레이션(테이블)을 처리하는 연산의 집합

## 📌 일반 집합 연산자

### 1. 합집합 (Union) - ∪
두 릴레이션의 모든 튜플을 포함 (중복 제거)

**조건**: 두 릴레이션의 차수(속성 개수)가 같아야 함

```
학생1: {김철수, 이영희}
학생2: {박민수, 김철수}

학생1 ∪ 학생2 = {김철수, 이영희, 박민수}
```

### 2. 교집합 (Intersection) - ∩
두 릴레이션에 공통으로 포함된 튜플

**조건**: 두 릴레이션의 차수가 같아야 함

```
학생1: {김철수, 이영희}
학생2: {박민수, 김철수}

학생1 ∩ 학생2 = {김철수}
```

### 3. 차집합 (Difference) - -
첫 번째 릴레이션에는 있고, 두 번째 릴레이션에는 없는 튜플

**조건**: 두 릴레이션의 차수가 같아야 함

```
학생1: {김철수, 이영희}
학생2: {박민수, 김철수}

학생1 - 학생2 = {이영희}
```

### 4. 카티션 프로덕트 (Cartesian Product) - ×
두 릴레이션의 모든 튜플을 조합

```
학생: {(김철수, 20), (이영희, 21)}
과목: {(수학), (영어)}

학생 × 과목 = {
    (김철수, 20, 수학),
    (김철수, 20, 영어),
    (이영희, 21, 수학),
    (이영희, 21, 영어)
}
```

## 📌 순수 관계 연산자

### 1. 셀렉트 (Select) - σ (시그마)
**조건을 만족하는 행(튜플)을 선택**

기호: σ조건(릴레이션)

```
학생 테이블:
학번 | 이름   | 학년
-----|--------|------
001  | 김철수 | 1
002  | 이영희 | 2
003  | 박민수 | 1

σ학년=1(학생) =
학번 | 이름   | 학년
-----|--------|------
001  | 김철수 | 1
003  | 박민수 | 1
```

**SQL 비교**
```sql
SELECT * FROM 학생 WHERE 학년 = 1;
```

### 2. 프로젝트 (Project) - π (파이)
**특정 열(속성)을 선택**

기호: π속성1,속성2(릴레이션)

```
학생 테이블:
학번 | 이름   | 학년
-----|--------|------
001  | 김철수 | 1
002  | 이영희 | 2

π이름,학년(학생) =
이름   | 학년
-------|------
김철수 | 1
이영희 | 2
```

**SQL 비교**
```sql
SELECT 이름, 학년 FROM 학생;
```

### 3. 조인 (Join) - ⋈ (보타이)
**공통 속성을 기준으로 두 릴레이션을 결합**

기호: R ⋈ S 또는 R ⋈조건 S

#### Natural Join (자연 조인)
```
학생:                    수강:
학번 | 이름              학번 | 과목
-----|------            -----|------
001  | 김철수            001  | 수학
002  | 이영희            002  | 영어

학생 ⋈ 수강 =
학번 | 이름   | 과목
-----|--------|------
001  | 김철수 | 수학
002  | 이영희 | 영어
```

#### Theta Join (세타 조인)
조건을 명시하여 조인

```
학생 ⋈학생.학번=수강.학번 수강
```

**SQL 비교**
```sql
SELECT * FROM 학생 JOIN 수강 ON 학생.학번 = 수강.학번;
```

### 4. 디비전 (Division) - ÷
**R ÷ S**: S의 모든 튜플과 관련 있는 R의 튜플을 선택

```
수강:                    과목:
학생 | 과목              과목
-----|------            ------
A    | 수학              수학
A    | 영어              영어
B    | 수학
C    | 수학
C    | 영어

수강 ÷ 과목 = {A, C}
(수학과 영어를 모두 수강한 학생)
```

## 📌 확장 관계 연산자

### 1. 세미 조인 (Semi Join) - ⋉
R ⋉ S: S와 조인 가능한 R의 튜플만 선택 (R의 속성만 유지)

### 2. 외부 조인 (Outer Join)
- **Left Outer Join**: 왼쪽 릴레이션의 모든 튜플 포함
- **Right Outer Join**: 오른쪽 릴레이션의 모든 튜플 포함
- **Full Outer Join**: 양쪽 모두의 튜플 포함

## 📌 복합 연산 예제

### 예제 1
**"1학년 학생의 이름과 학번을 조회"**

π이름,학번(σ학년=1(학생))

**SQL 비교**
```sql
SELECT 이름, 학번 FROM 학생 WHERE 학년 = 1;
```

### 예제 2
**"수학을 수강하는 학생의 이름"**

π이름(학생 ⋈ (σ과목='수학'(수강)))

**SQL 비교**
```sql
SELECT 학생.이름
FROM 학생 JOIN 수강 ON 학생.학번 = 수강.학번
WHERE 수강.과목 = '수학';
```

## 📌 관계 대수 기호 정리

| 연산자 | 기호 | 설명 | SQL 대응 |
|--------|------|------|----------|
| Select | σ (시그마) | 행 선택 (조건) | WHERE |
| Project | π (파이) | 열 선택 | SELECT 컬럼 |
| Join | ⋈ (보타이) | 결합 | JOIN |
| Division | ÷ | 나눗셈 | (복잡한 쿼리) |
| Union | ∪ | 합집합 | UNION |
| Intersection | ∩ | 교집합 | INTERSECT |
| Difference | - | 차집합 | EXCEPT/MINUS |
| Cartesian Product | × | 카티션 곱 | CROSS JOIN |

## 📌 실전 예제

### 문제 1
다음 관계 대수식의 의미를 SQL로 작성하시오.

**π이름,학과(σ학년≥3(학생))**

**답:**
```sql
SELECT 이름, 학과 FROM 학생 WHERE 학년 >= 3;
```

### 문제 2
"컴퓨터공학과 학생 중 2학년 학생의 이름"

**관계 대수:**
```
π이름(σ학과='컴퓨터공학' ∧ 학년=2(학생))
```

**SQL:**
```sql
SELECT 이름 FROM 학생 WHERE 학과 = '컴퓨터공학' AND 학년 = 2;
```

### 문제 3
"수학과 영어를 모두 수강한 학생"

**관계 대수:**
```
π학번(σ과목='수학'(수강)) ∩ π학번(σ과목='영어'(수강))
```

**SQL:**
```sql
SELECT 학번 FROM 수강 WHERE 과목 = '수학'
INTERSECT
SELECT 학번 FROM 수강 WHERE 과목 = '영어';
```

## 💡 암기 팁

### 기호 암기법
- **σ (시그마)**: **S**elect의 S
- **π (파이)**: **P**roject의 P
- **⋈ (보타이)**: 나비넥타이 → 두 개를 연결 → **조인**
- **÷ (나누기)**: 수학의 나눗셈 기호

### 연산 순서
1. **Select (σ)**: 먼저 조건으로 행을 걸러냄
2. **Project (π)**: 필요한 열만 선택
3. **Join (⋈)**: 마지막으로 테이블 결합
