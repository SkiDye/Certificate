# 정보처리기사 자격증 학습 가이드

## 📋 시험 개요

### 필기 시험
- **시험 시간**: 150분 (2시간 30분)
- **과목 수**: 5과목
- **문항 수**: 과목당 20문항, 총 100문항
- **합격 기준**: 과목당 40점 이상, 평균 60점 이상

### 실기 시험
- **시험 시간**: 180분 (3시간)
- **문제 유형**: 필답형
- **합격 기준**: 60점 이상

## 📚 필기 과목 구성

### 1과목: 소프트웨어 설계
- 요구사항 확인
- 화면 설계
- 애플리케이션 설계
- 인터페이스 설계

### 2과목: 소프트웨어 개발
- 데이터 입출력 구현
- 통합 구현
- 제품 소프트웨어 패키징
- 애플리케이션 테스트 관리
- 인터페이스 구현

### 3과목: 데이터베이스 구축
- SQL 응용
- SQL 활용
- 논리 데이터베이스 설계
- 물리 데이터베이스 설계
- 데이터 전환

### 4과목: 프로그래밍 언어 활용
- 서버 프로그램 구현
- 프로그래밍 언어 활용
- 응용 SW 기초 기술 활용

### 5과목: 정보시스템 구축관리
- 소프트웨어 개발 방법론 활용
- IT 프로젝트 정보 시스템 구축 관리
- 소프트웨어 개발 보안 구축
- 시스템 보안 구축

## 📖 학습 계획

### 1단계: 기초 다지기 (4주)
- [ ] 각 과목 이론 1회독
- [ ] 핵심 개념 요약 노트 작성
- [ ] 기본 용어 암기

### 2단계: 문제 풀이 (4주)
- [ ] 과목별 기출문제 풀이
- [ ] 오답 노트 작성
- [ ] 취약 부분 재학습

### 3단계: 실전 대비 (2주)
- [ ] 전체 모의고사 풀이
- [ ] 시간 배분 연습
- [ ] 최종 정리

## 🎯 실기 준비 전략

### 핵심 학습 영역
1. **SQL 작성** - 가장 많은 배점
2. **소프트웨어 설계** - UML, ERD
3. **프로그래밍** - C, Java, Python
4. **네트워크/보안** - 용어 및 개념
5. **신기술** - 최신 IT 트렌드

### 학습 방법
- 기출문제 반복 학습 (최근 3년)
- 손으로 직접 작성 연습
- 시간 제한 두고 모의고사 풀이

## 💡 학습 팁

1. **필기 시험**
   - 과목당 30분 배분 (100문제/150분)
   - 모르는 문제는 표시 후 나중에
   - 과목별 40점 컷 주의

2. **실기 시험**
   - SQL 문법 완벽 숙지
   - 최신 기출 경향 파악
   - 약어/영문 정확히 암기

3. **효율적 암기법**
   - 반복 학습 (에빙하우스 망각곡선)
   - 손으로 직접 작성
   - 개념 간 연관성 파악
