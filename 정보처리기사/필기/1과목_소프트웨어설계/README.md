# 1과목: 소프트웨어 설계

## 📌 과목 개요
소프트웨어 개발의 첫 단계인 설계에 관한 내용을 다룹니다.

## 📚 주요 학습 내용

### 1. 요구사항 확인
- **현행 시스템 분석**
  - 시스템 구성, 기능, 인터페이스 파악
  - DBMS, 네트워크 분석

- **요구사항 확인**
  - 기능적 요구사항 vs 비기능적 요구사항
  - 요구사항 분석 기법
  - 요구사항 명세 기법

- **분석 모델 검증**
  - 유스케이스 다이어그램
  - 정형 기술 검토

### 2. 화면 설계
- **UI 요구사항 확인**
  - UI 표준, 지침
  - 품질 요구사항

- **UI 설계**
  - 와이어프레임
  - 스토리보드
  - 프로토타입

### 3. 애플리케이션 설계
- **공통 모듈 설계**
  - 응집도(Cohesion): 높을수록 좋음
  - 결합도(Coupling): 낮을수록 좋음
  - 모듈화

- **객체지향 설계**
  - 캡슐화, 상속, 다형성
  - 디자인 패턴
  - GoF 패턴 23가지

### 4. 인터페이스 설계
- **시스템 인터페이스 요구사항 분석**
  - 인터페이스 구성 요소
  - 데이터 표준 확인

- **인터페이스 상세 설계**
  - 인터페이스 명세서 작성
  - 송수신 데이터 식별

## 🎯 핵심 키워드

### 디자인 패턴
- **생성 패턴**: Singleton, Factory, Abstract Factory, Builder, Prototype
- **구조 패턴**: Adapter, Bridge, Composite, Decorator, Facade, Proxy
- **행위 패턴**: Observer, Strategy, Template Method, Command, Iterator, State

### UML 다이어그램
- **구조적 다이어그램**: 클래스, 객체, 컴포넌트, 배치, 복합체 구조, 패키지
- **행위 다이어그램**: 유스케이스, 시퀀스, 커뮤니케이션, 상태, 활동, 타이밍

### 결합도 (낮을수록 좋음)
1. 내용 결합도 (최악)
2. 공통 결합도
3. 외부 결합도
4. 제어 결합도
5. 스탬프 결합도
6. 자료 결합도 (최선)

### 응집도 (높을수록 좋음)
1. 우연적 응집도 (최악)
2. 논리적 응집도
3. 시간적 응집도
4. 절차적 응집도
5. 통신적 응집도
6. 순차적 응집도
7. 기능적 응집도 (최선)
