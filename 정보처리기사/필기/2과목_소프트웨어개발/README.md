# 2과목: 소프트웨어 개발

## 📌 과목 개요
실제 소프트웨어를 구현하고 테스트하는 단계의 내용을 다룹니다.

## 📚 주요 학습 내용

### 1. 데이터 입출력 구현
- **자료구조**
  - 배열, 스택, 큐, 트리, 그래프
  - 선형 구조 vs 비선형 구조

- **정렬 알고리즘**
  - 버블, 선택, 삽입, 퀵, 병합, 힙 정렬
  - 시간 복잡도 비교

- **논리 데이터 저장소 확인**
  - 데이터 모델링
  - 정규화

### 2. 통합 구현
- **단위 모듈 구현**
  - IPC (Inter-Process Communication)
  - 공유 메모리, 소켓, 세마포어, 파이프

- **모듈 간 공통 기능 구현**
  - EAI (Enterprise Application Integration)
  - ESB (Enterprise Service Bus)

### 3. 제품 소프트웨어 패키징
- **제품 소프트웨어 패키징**
  - 릴리즈 노트 작성
  - 버전 관리

- **제품 소프트웨어 매뉴얼 작성**
  - 사용자 매뉴얼
  - 설치 매뉴얼

### 4. 애플리케이션 테스트 관리
- **테스트 케이스 설계**
  - 화이트박스 테스트
  - 블랙박스 테스트

- **통합 테스트**
  - 하향식(Top-Down): 스텁(Stub) 사용
  - 상향식(Bottom-Up): 드라이버(Driver) 사용

- **테스트 자동화 도구**
  - JUnit, Selenium, JMeter

### 5. 인터페이스 구현
- **인터페이스 구현**
  - JSON, XML 데이터 포맷
  - RESTful API

- **인터페이스 보안**
  - 암호화 기법
  - 인증/인가

## 🎯 핵심 키워드

### 정렬 알고리즘 시간복잡도
| 알고리즘 | 최선 | 평균 | 최악 |
|---------|------|------|------|
| 버블 정렬 | O(n²) | O(n²) | O(n²) |
| 선택 정렬 | O(n²) | O(n²) | O(n²) |
| 삽입 정렬 | O(n) | O(n²) | O(n²) |
| 퀵 정렬 | O(n log n) | O(n log n) | O(n²) |
| 병합 정렬 | O(n log n) | O(n log n) | O(n log n) |
| 힙 정렬 | O(n log n) | O(n log n) | O(n log n) |

### 테스트 기법

**화이트박스 테스트** (내부 구조)
- 기초 경로 커버리지
- 조건 커버리지
- 루프 테스트

**블랙박스 테스트** (기능)
- 동등 분할
- 경계값 분석
- 원인-결과 그래프

### EAI 구축 유형
- **Point-to-Point**: 1:1 직접 연결
- **Hub & Spoke**: 중앙 집중형
- **Message Bus**: 미들웨어 기반
- **Hybrid**: 혼합형

- **큐**: FIFO (First In First Out)
- **하향식 테스트**: 스텁(Stub) - 하위 모듈 대체
- **상향식 테스트**: 드라이버(Driver) - 상위 모듈 대체
