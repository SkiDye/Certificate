# 2과목: 전자 기기

## 📌 과목 개요
다양한 전자 기기의 동작 원리와 회로 구성을 학습합니다.

## 📚 주요 학습 내용

### 1. 증폭 회로
- **트랜지스터 증폭기**
  - 이미터 공통(CE) 증폭기
  - 베이스 공통(CB) 증폭기
  - 컬렉터 공통(CC) 증폭기

- **증폭도**
  - 전압 증폭도: Av = Vout/Vin
  - 전류 증폭도: Ai = Iout/Iin
  - 전력 증폭도: Ap = Pout/Pin

- **바이어스 회로**
  - 고정 바이어스
  - 자기 바이어스
  - 전압 분배 바이어스

### 2. 발진 회로
- **발진 조건**
  - 바크하우젠 조건
  - 루프 이득 ≥ 1
  - 위상 차이 = 0° 또는 360°

- **발진기 종류**
  - LC 발진기 (하틀리, 콜피츠)
  - RC 발진기 (윈 브리지)
  - 수정 발진기

### 3. 전원 회로
- **정류 회로**
  - 반파 정류
  - 전파 정류
  - 브리지 정류

- **평활 회로**
  - 커패시터 입력형
  - 초크 입력형
  - π형 필터

- **전압 안정화 회로**
  - 제너 다이오드 회로
  - 직렬 레귤레이터
  - 스위칭 레귤레이터

### 4. 디지털 논리 회로
- **조합 논리 회로**
  - 가산기 (Half Adder, Full Adder)
  - 감산기
  - 인코더/디코더
  - 멀티플렉서/디멀티플렉서

- **순서 논리 회로**
  - 플립플롭 (RS, JK, D, T)
  - 카운터
  - 레지스터
  - 시프트 레지스터

### 5. 연산 증폭기 (Op-Amp)
- **기본 특성**
  - 높은 입력 임피던스
  - 낮은 출력 임피던스
  - 높은 개방 이득

- **기본 회로**
  - 반전 증폭기: Av = -Rf/Ri
  - 비반전 증폭기: Av = 1 + Rf/Ri
  - 전압 폴로워: Av = 1

- **응용 회로**
  - 가산기/감산기
  - 적분기/미분기
  - 비교기

### 6. 마이크로프로세서
- **기본 구조**
  - CPU (중앙처리장치)
  - 메모리 (RAM, ROM)
  - I/O 포트

- **명령어**
  - 데이터 전송
  - 산술 연산
  - 논리 연산
  - 분기 명령

## 🎯 핵심 회로 정리

### 증폭기 특성 비교

| 구분 | CE (이미터 공통) | CB (베이스 공통) | CC (컬렉터 공통) |
|------|-----------------|-----------------|------------------|
| 전압 증폭도 | 높음 | 높음 | 1 (전압 폴로워) |
| 전류 증폭도 | 높음 | 1 미만 | 높음 |
| 입력 임피던스 | 중간 | 낮음 | 높음 |
| 출력 임피던스 | 중간 | 높음 | 낮음 |
| 위상 반전 | 있음 | 없음 | 없음 |
| 용도 | 일반 증폭 | 고주파 증폭 | 임피던스 정합 |

### 발진기 종류

| 발진기 | 주파수 결정 | 특징 |
|--------|------------|------|
| 하틀리 | L, C | 탭 인덕터 사용 |
| 콜피츠 | L, C | 분할 커패시터 |
| 윈 브리지 | R, C | 저주파용 |
| 수정 | 수정 진동자 | 고안정도 |

### 정류 회로

| 방식 | 다이오드 수 | 출력 전압 | 리플 주파수 |
|------|------------|----------|------------|
| 반파 정류 | 1개 | Vm/π | f |
| 전파 정류 | 2개 | 2Vm/π | 2f |
| 브리지 정류 | 4개 | 2Vm/π | 2f |

## 💡 암기 팁

### Op-Amp 증폭도
- **반전**: Av = -Rf/Ri (마이너스!)
- **비반전**: Av = 1 + Rf/Ri (1을 더함!)
- **전압 폴로워**: Av = 1 (그대로!)

### 플립플롭 종류
- **RS**: Set/Reset
- **JK**: RS 개선형 (만능)
- **D**: Data (1비트 저장)
- **T**: Toggle (반전)

### 정류 회로 선택
- **반파**: 간단, 효율 낮음
- **전파**: 센터탭 변압기 필요
- **브리지**: 가장 효율적, 다이오드 4개

## 📊 자주 나오는 문제

### 유형 1: Op-Amp 증폭도
```
문제: 반전 증폭기에서 Rf=100kΩ, Ri=10kΩ일 때 증폭도는?
풀이: Av = -Rf/Ri = -100k/10k = -10
```

### 유형 2: 정류 회로 출력
```
문제: 입력 전압이 100V(peak)인 전파 정류기의 평균 출력 전압은?
풀이: Vdc = 2Vm/π = 2×100/3.14 ≈ 63.7V
```

### 유형 3: 증폭기 구분
```
문제: 입력과 출력의 위상이 같고, 전압 증폭도가 1인 증폭기는?
답: 컬렉터 공통(CC) 증폭기 또는 전압 폴로워
```

### 유형 4: 플립플롭
```
문제: 이전 출력이 다음 입력이 되어 계속 반전되는 플립플롭은?
답: T 플립플롭
```
