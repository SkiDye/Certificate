# 측정 기기 사용법 완벽 가이드

## 📌 멀티미터 (Multimeter)

### 기본 사용법

#### 전압 측정 (DC, AC)
```
1. 다이얼을 V (전압) 위치로
   - DC: V⎓ 또는 VDC
   - AC: V~ 또는 VAC

2. 측정 범위 선택
   - 예상 전압보다 높은 범위
   - 모를 때는 최대 범위에서 시작

3. 프로브 연결
   - 빨강(+): 측정 단자
   - 검정(-): GND 또는 COM

4. 측정
   - 회로에 병렬로 연결
   - 값 읽기

예시:
  5V 전원 측정
  → 20V 범위 선택
  → 빨강을 +, 검정을 GND에
  → 5V 표시 확인
```

#### 전류 측정 (DC, AC)
```
1. 다이얼을 A (전류) 위치로
   - DC: A⎓ 또는 ADC
   - AC: A~ 또는 AAC

2. 측정 범위 선택
   - 예상 전류보다 높은 범위
   - 작은 전류: mA 단자 사용
   - 큰 전류: 10A 단자 사용

3. 프로브 연결
   - 빨강: A 또는 mA 단자
   - 검정: COM 단자

4. 측정
   - 회로에 직렬로 연결
   - 회로를 끊고 중간에 삽입
   - 값 읽기

⚠️ 주의:
  - 절대 병렬 연결 금지!
  - 단락 위험!
  - 측정 후 프로브를 V 단자로 복귀
```

#### 저항 측정
```
1. 다이얼을 Ω (저항) 위치로

2. 측정 범위 선택
   - 예상 저항보다 높은 범위

3. 프로브 연결
   - 빨강, 검정 순서 무관

4. 측정
   - 전원 OFF 상태에서 측정!
   - 회로에서 한쪽 다리 분리
   - 값 읽기

예시:
  1kΩ 저항 측정
  → 2kΩ 또는 20kΩ 범위
  → 1000 또는 1.00k 표시
```

#### 다이오드 테스트
```
1. 다이얼을 다이오드 모드 (→|◄)

2. 프로브 연결
   - 빨강: 애노드 (+)
   - 검정: 캐소드 (-)

3. 측정
   - 순방향: 0.5~0.7V 표시
   - 역방향: OL 표시

정상:
  순방향 0.6V, 역방향 OL

불량:
  양방향 OL → 단선
  양방향 0V → 단락
```

#### 도통 테스트 (비퍼)
```
1. 다이얼을 비퍼 모드 (♪)

2. 프로브를 측정점에

3. 도통 확인
   - 도통: 비프음 발생
   - 개방: 무음

용도:
  - 배선 연결 확인
  - 단락 확인
  - 스위치 동작 확인
```

### 측정 시 주의사항
```
1. 전압/저항 측정 후 반드시 프로브 위치 확인
2. 전류 측정은 직렬! (병렬 연결 시 단락)
3. 저항 측정은 전원 OFF!
4. 범위 선택 잘못 시 fuse 끊어짐
5. 고전압 측정 시 안전 주의
```

## 📌 오실로스코프 (Oscilloscope)

### 기본 설정

#### 프로브 보상
```
⚠️ 측정 전 반드시 실시!

1. 프로브를 CH1에 연결
2. 프로브 팁을 보상 단자(CAL)에
3. 파형 확인
   - 정상: 깨끗한 구형파
   - 과보상: 위아래 튀어나옴
   - 부족보상: 둥글게 뭉개짐
4. 프로브의 조정 나사로 조정
5. 깨끗한 구형파가 될 때까지
```

#### Time/Div 설정
```
수평축 (시간) 조정

설정:
  - 1ms/div: 저주파 (수십 Hz)
  - 100μs/div: 중간 주파수
  - 10μs/div: 고주파 (수 kHz)
  - 1μs/div: 고주파 (수십 kHz)

팁:
  - 파형 2~3주기가 화면에 보이게
  - 너무 빠르면 점처럼 보임
  - 너무 느리면 선처럼 보임
```

#### Volt/Div 설정
```
수직축 (전압) 조정

설정:
  - 5V/div: 큰 신호 (12V, 15V)
  - 2V/div: 중간 신호
  - 1V/div: 작은 신호
  - 500mV/div: 미세 신호

팁:
  - 파형이 화면의 절반 이상 차지하게
  - 너무 크면 상하 잘림
  - 너무 작으면 측정 부정확
```

#### 트리거 설정
```
파형을 화면에 정지시키기

모드:
  - Auto: 자동 (일반적)
  - Normal: 트리거 조건 만족 시만
  - Single: 한 번만 캡처

레벨:
  - 파형의 어느 전압에서 시작할지
  - 보통 파형의 중간쯤

Slope:
  - Rising: 상승 에지에서
  - Falling: 하강 에지에서
```

### 측정 방법

#### 주파수 측정
```
1. 파형을 안정적으로 표시
2. Time/Div로 주기(T) 확인
3. 계산: f = 1/T

예시:
  화면에 1주기 = 5칸
  Time/Div = 200μs
  → T = 5 × 200μs = 1ms = 0.001s
  → f = 1/0.001 = 1000Hz = 1kHz

또는:
  - Measure 메뉴 → Frequency 선택
  - 자동으로 표시
```

#### 진폭 측정
```
1. 파형을 안정적으로 표시
2. Volt/Div로 진폭 확인
3. Peak-to-Peak 측정

예시:
  화면에 파형 높이 = 4칸
  Volt/Div = 2V
  → Vpp = 4 × 2V = 8V
  → Vpeak = 8V / 2 = 4V
  → Vrms = 4V / √2 = 2.83V

또는:
  - Measure 메뉴 → Vpp 선택
```

#### 위상차 측정
```
두 채널 사용:
1. CH1과 CH2에 각각 신호
2. 두 파형 표시
3. 같은 지점 간격 측정

계산:
  위상차(도) = (시간차 / 주기) × 360°

예시:
  주기 = 10칸
  시간차 = 2.5칸
  → 위상차 = (2.5/10) × 360° = 90°
```

### 파형 분석

#### 정상 파형
```
사인파:
  - 부드러운 곡선
  - 왜곡 없음
  - 일정한 진폭

구형파:
  - 수직 상승/하강
  - 평평한 상단/하단
  - 오버슈트/언더슈트 최소

삼각파:
  - 직선 상승/하강
  - 일정한 기울기
```

#### 비정상 파형
```
왜곡:
  - 찌그러진 파형
  - 클리핑 (잘림)
  - 증폭기 과부하

잡음:
  - 파형에 지저분한 노이즈
  - 접지 불량, 간섭

리플:
  - 파형에 작은 파동
  - 전원 회로 평활 불량
```

## 📌 함수발생기 (Function Generator)

### 기본 설정

#### 파형 선택
```
버튼 또는 다이얼:
  - 사인파 (∿): 일반 신호
  - 구형파 (⎍): 디지털 신호
  - 삼각파 (△): 선형 변화

용도:
  - 사인파: 증폭기 테스트
  - 구형파: 디지털 회로
  - 삼각파: 적분/미분 회로
```

#### 주파수 설정
```
1. 범위 선택
   - Hz, kHz, MHz

2. 주파수 다이얼 또는 버튼
   - 숫자 입력 or 다이얼 회전

예시:
  1kHz 사인파 생성
  → 파형: 사인파 선택
  → 범위: kHz
  → 주파수: 1
```

#### 진폭 설정
```
1. Amplitude 다이얼 조정

2. 단위 확인
   - Vpp (Peak-to-Peak)
   - Vrms (실효값)

예시:
  5Vpp 출력
  → Amplitude: 5
  → 단위: Vpp
```

#### DC 오프셋
```
DC Offset 다이얼:
  - 파형을 위/아래로 이동
  - 0V 중심 → 양전압만 or 음전압만

예시:
  0~5V 구형파 (TTL 레벨)
  → Amplitude: 5Vpp
  → Offset: +2.5V
  → 결과: 0~5V
```

### 출력 연결
```
1. 출력 단자에 BNC 케이블 연결

2. 회로에 연결
   - 중심: 신호
   - 외곽: GND

3. Output On/Off 확인
   - 출력 활성화 버튼

4. 부하 임피던스 설정
   - 50Ω (종단)
   - High-Z (개방)
```

## 📌 직류 전원 공급 장치 (DC Power Supply)

### 기본 사용법

#### 전압 설정
```
1. Voltage 다이얼 조정
2. 원하는 전압 표시
3. 미세 조정 (Fine)

예시:
  +5V 출력
  → Voltage: 5.00V
```

#### 전류 제한 설정 (중요!)
```
1. Current Limit 다이얼 조정
2. 최대 허용 전류 설정

⚠️ 반드시 설정!
  - 회로 보호
  - 단락 시 전류 제한
  - 보통 100mA~500mA

예시:
  디지털 회로 (최대 200mA)
  → Current Limit: 300mA
```

#### 출력 On/Off
```
1. 전압/전류 설정 확인
2. Output 버튼 → On
3. LED 점등 확인
4. 전압/전류 표시 확인

사용 후:
  → Output 버튼 → Off
```

### 듀얼 전원 사용
```
+/- 전원이 필요한 경우:
  (예: Op-Amp ±12V)

설정:
  - CH1: +12V
  - CH2: -12V (Tracking 기능)
  - 또는 직렬 연결

연결:
  - CH1 +: +12V
  - GND: 0V
  - CH2 -: -12V
```

## ⚠️ 안전 주의사항

### 측정 전
```
1. 전원 범위 확인
2. 프로브 상태 확인 (단선, 파손)
3. 접지 확인
4. 범위 설정 확인
```

### 측정 중
```
1. 한 손 사용 (감전 방지)
2. 고전압 주의
3. 프로브 짧은 접촉
4. 회로 변경 시 전원 차단
```

### 측정 후
```
1. 전원 차단
2. 프로브 정리
3. 측정값 기록
4. 장비 정리
```
