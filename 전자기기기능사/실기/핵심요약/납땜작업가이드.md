# 납땜 작업 완벽 가이드

## 📌 납땜 기초 이론

### 납땜이란?
```
납(주석 합금)을 녹여서 전자 부품을 PCB에 영구적으로 고정하고
전기적 연결을 만드는 작업

온도: 350~400°C
시간: 부품당 2~3초
```

### 좋은 납땜 vs 나쁜 납땜

#### 좋은 납땜 (양호)
```
✅ 모양: 후지산 모양 (△)
✅ 표면: 매끄럽고 광택
✅ 납의 양: 적당 (과하지도 부족하지도 않음)
✅ 접합: 패드와 부품 다리에 골고루
✅ 색상: 은색 광택
```

#### 나쁜 납땜 (불량)
```
❌ 냉납: 납이 제대로 녹지 않음 (거칠고 흐림)
❌ 과열: 납이 타서 검게 변함
❌ 브리지: 인접 패드 간 단락
❌ 부족: 납이 너무 적어 접합 불량
❌ 과다: 납이 너무 많아 뭉쳐있음
```

## 🔧 납땜 도구 및 준비물

### 필수 도구
```
1. 납땜 인두 (Soldering Iron)
   - 온도: 350~400°C
   - 팁: 일자형 또는 D형
   - 전력: 40~60W

2. 납 (Solder Wire)
   - 종류: 60/40 (주석60% 납40%) 또는 무연 납
   - 굵기: 0.8~1.0mm
   - 플럭스 내장형 사용

3. 납땜 인두 받침대
   - 인두 거치대
   - 스펀지 (팁 청소용)
   - 황동 수세미 (팁 청소용)

4. 기타 도구
   - 니퍼 (부품 다리 자르기)
   - 롱노즈 (부품 다리 구부리기)
   - 핀셋
   - 제3의 손 (기판 고정대)
   - 흡입기/위크 (실수 수정용)
```

### 안전 장비
```
⚠️ 필수!
- 환기: 납 증기 배출
- 안전 안경: 납 튐 방지
- 장갑: 화상 방지 (작업 시 제외)
- 작업 매트: 정전기 방지
```

## 📋 납땜 작업 순서 (PCB 조립)

### 1단계: 회로 스케치 (30~40분)
```
주어진 회로도를 보고 스케치 용지에 그리기

체크포인트:
- [ ] 모든 부품 그리기
- [ ] 연결선 정확히
- [ ] 부품 값 표기
- [ ] 극성 부품 방향 표시
- [ ] 전원(Vcc, GND) 표시
```

### 2단계: 부품 준비 및 배치 (20분)
```
1. 부품 확인
   - [ ] 저항값 컬러 코드로 확인
   - [ ] 커패시터 용량 확인
   - [ ] IC, 다이오드, LED 극성 확인
   - [ ] 트랜지스터 핀 배치 확인

2. 부품 다리 정리
   - [ ] 저항 다리 직각으로 구부리기
   - [ ] 길이 조절 (PCB 두께 + 2mm)
   - [ ] 극성 부품 표시

3. 부품 배치 순서
   - ① 낮은 부품부터 (저항, 다이오드)
   - ② 중간 높이 (커패시터, IC 소켓)
   - ③ 높은 부품 (전해 커패시터, IC)
```

### 3단계: 납땜 작업 (90~120분)
```
⚠️ 가장 중요한 단계!

기본 납땜 순서:
1. 인두 예열 (5분, 350~400°C)
2. 팁 청소 (스펀지에 문지르기)
3. 팁에 소량의 납 묻히기 (열전도 향상)
4. 납땜 실시
5. 팁 청소
6. 다음 부품

한 개 부품 납땜 순서:
1. PCB 뒷면에 부품 다리 삽입
2. 앞면에서 부품 고정
3. 뒷면 패드에 인두 팁 대기 (1초)
4. 납 와이어를 패드와 부품 다리에 대기
5. 납이 녹아서 퍼지면 납 제거 (1~2초)
6. 인두 제거 (3초 이내 완료)
7. 식을 때까지 기다림 (5초)
8. 부품 다리 자르기 (니퍼)
```

#### 납땜 상세 기법
```
올바른 방법:
1. 인두를 패드와 부품 다리에 동시 접촉
2. 1초 대기 (예열)
3. 납 와이어를 인두 반대편에서 접촉
4. 납이 녹아 퍼지면 납 먼저 제거
5. 0.5초 후 인두 제거

⏱️ 타이밍:
- 전체 시간: 2~3초
- 1초: 예열
- 1~2초: 납 녹이기
- 즉시: 인두 제거

🌡️ 온도 확인:
- 납이 즉시 녹으면 OK
- 3초 이상 걸리면 온도 부족
- 연기 많이 나면 과열
```

### 4단계: 검사 및 수정 (20분)
```
육안 검사:
- [ ] 모든 부품 납땜 완료
- [ ] 냉납, 브리지 없는지
- [ ] 부품 다리 적절히 잘랐는지
- [ ] 극성 부품 방향 확인
- [ ] IC 올바르게 삽입 (핀 번호)

멀티미터 검사:
- [ ] Vcc-GND 간 단락 없는지 (저항 측정)
- [ ] 주요 연결점 도통 확인

수정 (필요 시):
- 브리지 → 흡입기로 납 제거
- 냉납 → 재납땜
- 과다 → 위크로 흡수
```

### 5단계: 동작 확인 및 측정 (60분)
```
1. 전원 인가 전 최종 점검
   - [ ] 모든 연결 확인
   - [ ] 전원 극성 확인
   - [ ] 전류 제한 설정

2. 전원 인가
   - 전압 천천히 올리기
   - 전류 확인 (과전류 주의)
   - 발열 확인

3. 오실로스코프 측정
   - 파형 확인
   - 주파수 측정
   - 진폭 측정

4. 측정값 기록
   - 요구 항목 모두 측정
   - 답안지 작성
```

## ⚠️ 납땜 실수 및 대처

### 자주 하는 실수

#### 1. 브리지 (Bridge) - 인접 패드 단락
```
원인:
- 납이 너무 많음
- 인두 팁이 너무 큼
- 패드 간격이 좁음

대처:
1. 흡입기로 과다한 납 제거
2. 플럭스 추가
3. 인두로 납을 각 패드로 분리
4. 위크(Wick)로 흡수
```

#### 2. 냉납 (Cold Joint)
```
원인:
- 온도 부족
- 납땜 시간 부족
- 부품/패드가 차가움

대처:
1. 온도 확인 (350~400°C)
2. 재납땜 (충분한 예열)
3. 팁 청소
```

#### 3. 과열 (Overheating)
```
원인:
- 너무 오래 가열 (5초 이상)
- 온도 너무 높음

증상:
- 납이 검게 변함
- PCB 패드 들뜸
- 부품 손상

대처:
- 손상된 부품 교체
- 들뜬 패드는 점수 감점
```

#### 4. 부품 방향 틀림
```
⚠️ 실기에서 가장 치명적!

극성 부품:
- LED: 긴 다리 = +
- 전해 커패시터: 긴 다리 = +
- 다이오드: 띠 = 캐소드(-)
- IC: 점/홈 확인

대처:
- 발견 즉시 교체!
- 흡입기로 납 제거 후 부품 제거
- 방향 확인 후 재장착
```

## 💡 납땜 실전 팁

### 속도 향상
```
1. 부품 미리 준비
   - 다리 미리 구부리기
   - 길이 미리 맞추기
   - 극성 표시

2. 작업 순서 최적화
   - 같은 종류 부품 연속 작업
   - 저항 → 다이오드 → 커패시터 → IC

3. 양손 사용
   - 왼손: 부품 고정
   - 오른손: 인두
   (왼손잡이는 반대)

4. 리듬 타기
   - 예열 1초, 납땜 1초, 제거
   - 반복 숙달
```

### 품질 향상
```
1. 팁 관리
   - 작업 전후 청소
   - 항상 납 코팅 유지
   - 산화 방지

2. 적정 온도 유지
   - 350~400°C
   - 납이 즉시 녹는 온도

3. 적정 납 사용
   - 후지산 모양 (△)
   - 너무 많지도 적지도 않게
   - 광택 나는 표면

4. 실수 최소화
   - 한 번에 정확히
   - 재납땜 최소화
   - 과열 주의
```

### 시간 배분
```
총 4시간 중:

스케치: 30분
  - 서두르지 말고 정확히
  - 한 번 그린 건 수정 어려움

부품 준비: 20분
  - 컬러 코드 정확히 확인
  - 극성 미리 표시

납땜: 90~120분 (가장 많은 시간)
  - 저항 20~30개: 30분
  - 커패시터: 20분
  - 다이오드/LED: 10분
  - 트랜지스터/IC: 20분
  - 기타: 20분
  - 여유: 20분

검사: 20분
  - 육안 검사
  - 단락 확인
  - 수정

측정: 60분
  - 동작 확인
  - 오실로스코프
  - 답안 작성
```

## 🔥 납땜 안전 수칙

### 화상 방지
```
⚠️ 인두 온도: 350~400°C!

1. 인두 다룰 때
   - 손잡이만 잡기
   - 팁 절대 만지지 않기
   - 작업 중 인두 거치대에

2. 화상 시 응급처치
   - 즉시 찬물에 10분
   - 수포 터뜨리지 않기
   - 화상 연고

3. 주변 주의
   - 전선 녹을 수 있음
   - 플라스틱 부품 주의
   - 작업대 매트 사용
```

### 납 중독 방지
```
⚠️ 납 증기는 유독!

1. 환기
   - 환풍기 사용
   - 창문 열기
   - 납 흄 흡입기 (있으면)

2. 개인 위생
   - 작업 후 손 씻기
   - 음식 먹기 전 필수
   - 작업 중 음식 금지

3. 증상 (4시간 작업 시)
   - 어지러움
   - 손 떨림
   - 두통
   → 휴식, 환기
```

### 전기 안전
```
1. 전원 차단
   - 납땜 중 전원 OFF
   - 측정 시에만 전원 ON

2. 감전 주의
   - 젖은 손 금지
   - 한 손 작업
   - 절연 공구 사용

3. 단락 주의
   - 브리지 확인
   - 전원 인가 전 점검
```

## 📚 연습 방법

### 집에서 연습
```
준비물 구매 (2~3만원):
1. 납땜 인두 + 받침대
2. 납 (60/40 또는 무연)
3. 브레드보드 (연습용)
4. 만능 기판 (PCB)
5. 부품 세트 (저항, LED, IC 등)

연습 순서:
1주차: 저항만 납땜 (50개)
  - 깔끔한 납땜 모양 익히기
  - 2~3초 타이밍 익히기

2주차: 극성 부품 (LED, 다이오드)
  - 방향 확인 습관
  - 커패시터 납땜

3주차: IC, 트랜지스터
  - 핀 번호 확인
  - 다리 많은 부품

4주차: 전체 회로
  - 큐넷 공개문제 회로
  - 시간 재며 완성
```

### 공개문제 활용
```
큐넷 홈페이지:
1. 로그인
2. 자료실 → 전자기기기능사
3. 공개문제 다운로드
   - 1,2,3번 문제
   - 4,5,6번 문제
   - 7,8,9번 문제

연습:
- 회로도 이해
- 부품 리스트 작성
- 실제 부품 구매
- 조립 연습 (여러 번!)
```
