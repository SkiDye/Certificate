# 전자기기기능사 실기 준비

## 📌 실기 시험 개요
- **시험 시간**: 4시간
- **시험 방식**: 작업형 (브레드보드 회로 구성 + 측정)
- **합격 기준**: 100점 만점 중 60점 이상

### 시험 구성 (중요!)
```
1단계: 회로도 분석 및 부품 확인 (20~30분)
  - 주어진 회로도 분석
  - 부품 값 확인 (저항 컬러 코드)

2단계: 브레드보드 회로 구성 (120~150분) ⚡⚡⚡ 가장 중요!
  - 브레드보드에 부품 꽂기
  - 점퍼 와이어로 연결
  - 접촉 불량 없이 깔끔하게!

3단계: 동작 확인 및 측정 (60~90분)
  - 회로 동작 테스트
  - 오실로스코프 파형 측정
  - 멀티미터로 전압/전류 측정
  - 답안 작성
```

## 🔍 공개문제 정보 (필독!)

### 큐넷 공개문제
- **큐넷 홈페이지**(www.q-net.or.kr)에 **모든 문제가 공개**되어 있음!
- 공개문제 중 하나가 **그대로** 출제됨

### 문제 구성
```
그룹 1: 1번, 2번, 3번 문제 (발진부 다름)
그룹 2: 4번, 5번, 6번 문제 (발진부 다름)
그룹 3: 7번, 8번, 9번 문제 (99진 계수기, 발진부 다름)
```

### 출제 패턴
- 첫 시험: 1, 2, 3번 중 하나 출제
- 다음 시험: 4, 5, 6번 중 하나 출제
- 그 다음: 7, 8, 9번 중 하나 출제
- 반복...

### ⭐ 전략
```
1. 큐넷에서 공개문제 다운로드
2. 9개 회로 모두 이해
3. 최소 3~5개 회로는 실제로 만들어보기
4. 회로 패턴 익히기 (발진부만 다름)
5. 시험장에서 나온 문제 바로 시작!
```

## 🎯 출제 영역 및 배점

### 1. 브레드보드 회로 구성 (★★★★★) - 약 60점
**가장 중요한 영역!**

**주요 출제 유형**
- ⚡ **브레드보드에 회로 구성** (주력)
- 부품 정확히 꽂기
- 점퍼 와이어로 연결
- 극성 부품 방향 확인

**평가 항목**
- 회로 구성의 정확성 (회로도대로 연결)
- **접촉 불량 없음** (모든 부품 꽉 꽂기)
- 배선의 정확성 및 깔끔함
- 작업 시간
- 부품 방향 (극성 부품 틀리면 0점!)

**자주 하는 실수 (감점)**
```
❌ 접촉 불량: 부품/와이어가 헐거움
❌ IC 방향 틀림: 점/홈 반대로
❌ 극성 틀림: LED, 커패시터 방향 반대
❌ 배선 누락: 연결 안 된 곳 있음
✅ 정확한 회로: 회로도대로, 접촉 확실, 극성 정확
```

### 2. 측정 및 동작 확인 (★★★★) - 약 30점
**측정 기기 사용**
- 멀티미터 사용

- 함수발생기 설정
- 전원 공급 장치 사용

**동작 확인**
- 회로 동작 테스트
- 파형 측정 및 기록
- 전압/전류 측정

### 3. 안전 및 작업 태도 (★★★) - 약 10점

- 장비 올바른 사용

### 1단계: 문제 파악 (10분)
```
1. 회로도 정확히 읽기
2. 필요한 부품 확인
```

### 2단계: 부품 식별 및 체크 (20분)
```
1. 제공된 부품 확인
```

```
3. 부품 순서대로 배선
4. 배선은 짧고 정확하게
5. 극성 부품 방향 재확인
6. 납땜 (있는 경우)
```

### 4단계: 동작 확인 (60분)
```
1. 육안 검사 (배선, 납땜 상태)
2. 멀티미터로 단락 확인
3. 전원 인가 전 최종 점검
4. 전원 인가 (전류 제한 설정)
5. 동작 확인 및 측정
6. 결과 기록
```

### 5단계: 최종 점검 (30분)
```
1. 측정값 재확인
2. 답안 작성
3. 배선 정리
4. 작업대 정리
```

## 🔍 부품 식별 핵심

### 저항 컬러 코드
```
4색 띠: [1][2][승수][오차]
5색 띠: [1][2][3][승수][오차]

자주 쓰이는 값:
- 갈흑갈금: 100Ω
- 갈흑적금: 1kΩ
- 갈흑등금: 10kΩ
- 갈흑황금: 100kΩ
```

### 커패시터
```
세라믹: 104 = 10 × 10⁴ pF = 100nF = 0.1μF
전해: 극성 표시 확인 (긴 다리가 +)
```

### IC 핀 번호
```
- 위에서 봤을 때 왼쪽 위가 1번
- 반시계 방향으로 증가
- 점(dot) 또는 홈(notch)으로 1번 핀 표시
```

### 트랜지스터
```
- 데이터시트 확인 필수
- BCE 배치 (Base, Collector, Emitter)
- 멀티미터로 다이오드 테스트
```

## ⚠️ 실기 주의사항

### 시작 전
1. **회로도 정확히 읽기**
   - 부품 값 확인
   - 연결 관계 파악
   - 전원 극성 확인

2. **부품 확인**
   - 제공된 부품 체크
   - 불량 부품 교체 요청
   - 예비 부품 확인

### 작업 중
1. **배선 주의**
   - 짧고 정확하게
   - 색상 구분 (빨강=VCC, 검정=GND)
   - 교차 최소화

2. **극성 부품**
   - LED: 긴 다리가 +
   - 전해 커패시터: 긴 다리가 +
   - 다이오드: 띠가 있는 쪽이 캐소드(-)
   - IC: 핀 번호 확인

3. **납땜 (있는 경우)**
   - 인두 온도 적정 (350~400°C)
   - 납땜 시간 짧게 (3초 이내)
   - 충분한 납 사용
   - 브리지 주의

### 측정 시
1. **전원 인가 전**
   - 단락 확인
   - 배선 재확인
   - 전류 제한 설정

2. **측정**
   - 멀티미터 레인지 설정
   - 프로브 위치 확인
   - 측정값 기록
