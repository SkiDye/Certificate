# 전자기기기능사 실기 준비

## 📌 실기 시험 개요
- **시험 시간**: 약 4시간
- **시험 방식**: 작업형 (실제 회로 제작 및 측정)
- **합격 기준**: 100점 만점 중 60점 이상

## 🎯 출제 영역 및 배점

### 1. 회로 제작 (★★★★★) - 약 60점
**가장 중요한 영역!**

**주요 출제 유형**
- 브레드보드 회로 구성
- 납땜을 이용한 PCB 제작
- 부품 배치 및 배선
- 극성 부품 방향 확인

**평가 항목**
- 회로 구성의 정확성
- 배선의 정확성 및 깔끔함
- 납땜 상태
- 작업 시간

### 2. 측정 및 동작 확인 (★★★★) - 약 30점
**측정 기기 사용**
- 멀티미터 사용
- 오실로스코프 파형 확인
- 함수발생기 설정
- 전원 공급 장치 사용

**동작 확인**
- 회로 동작 테스트
- 파형 측정 및 기록
- 전압/전류 측정

### 3. 안전 및 작업 태도 (★★★) - 약 10점
- 전기 안전 수칙 준수
- 장비 올바른 사용
- 작업장 정리정돈
- 작업 절차 준수

## 🔧 실기 작업 프로세스

### 1단계: 문제 파악 (10분)
```
1. 회로도 정확히 읽기
2. 필요한 부품 확인
3. 작업 순서 계획
4. 측정 항목 파악
```

### 2단계: 부품 식별 및 체크 (20분)
```
1. 제공된 부품 확인
2. 저항값 컬러 코드로 확인
3. 커패시터 용량 확인
4. IC, 트랜지스터 핀 배치 확인
5. 극성 부품 (+/-) 표시
```

### 3단계: 회로 구성 (120분)
```
1. 회로도대로 부품 배치
2. 전원 배선 먼저 (VCC, GND)
3. 부품 순서대로 배선
4. 배선은 짧고 정확하게
5. 극성 부품 방향 재확인
6. 납땜 (있는 경우)
```

### 4단계: 동작 확인 (60분)
```
1. 육안 검사 (배선, 납땜 상태)
2. 멀티미터로 단락 확인
3. 전원 인가 전 최종 점검
4. 전원 인가 (전류 제한 설정)
5. 동작 확인 및 측정
6. 결과 기록
```

### 5단계: 최종 점검 (30분)
```
1. 측정값 재확인
2. 답안 작성
3. 배선 정리
4. 작업대 정리
```

## 📐 측정 기기 사용법

### 멀티미터
```
- 전압 측정: 병렬 연결
- 전류 측정: 직렬 연결

- 다이오드 테스트: 다이오드 모드
- 도통 테스트: 비퍼 모드

- Time/Div 설정

- 트리거 레벨 조정
- 주파수, 진폭 측정
```

### 함수발생기
```
- 파형 선택 (사인파, 구형파, 삼각파)

- 진폭 설정
- DC 오프셋 설정
```

## 🔍 부품 식별 핵심

### 저항 컬러 코드
```
4색 띠: [1][2][승수][오차]
5색 띠: [1][2][3][승수][오차]

자주 쓰이는 값:
- 갈흑갈금: 100Ω
- 갈흑적금: 1kΩ
- 갈흑등금: 10kΩ
- 갈흑황금: 100kΩ
```

### 커패시터
```
세라믹: 104 = 10 × 10⁴ pF = 100nF = 0.1μF
전해: 극성 표시 확인 (긴 다리가 +)
```

### IC 핀 번호
```
- 위에서 봤을 때 왼쪽 위가 1번
- 반시계 방향으로 증가
- 점(dot) 또는 홈(notch)으로 1번 핀 표시
```

### 트랜지스터
```
- 데이터시트 확인 필수
- BCE 배치 (Base, Collector, Emitter)
- 멀티미터로 다이오드 테스트
```

## ⚠️ 실기 주의사항

### 시작 전
1. **회로도 정확히 읽기**
   - 부품 값 확인
   - 연결 관계 파악
   - 전원 극성 확인

2. **부품 확인**
   - 제공된 부품 체크
   - 불량 부품 교체 요청
   - 예비 부품 확인

### 작업 중
1. **배선 주의**
   - 짧고 정확하게
   - 색상 구분 (빨강=VCC, 검정=GND)
   - 교차 최소화

2. **극성 부품**
   - LED: 긴 다리가 +
   - 전해 커패시터: 긴 다리가 +
   - 다이오드: 띠가 있는 쪽이 캐소드(-)
   - IC: 핀 번호 확인

3. **납땜 (있는 경우)**
   - 인두 온도 적정 (350~400°C)
   - 납땜 시간 짧게 (3초 이내)
   - 충분한 납 사용
   - 브리지 주의

### 측정 시
1. **전원 인가 전**
   - 단락 확인
   - 배선 재확인
   - 전류 제한 설정

2. **측정**
   - 멀티미터 레인지 설정
   - 프로브 위치 확인
   - 측정값 기록

## 💡 합격 팁

### 시간 배분
```
- 문제 파악: 10분
- 부품 확인: 20분
- 회로 구성: 120분 (가장 중요!)
- 동작 확인: 60분
- 최종 점검: 30분
```

### 점수 올리기
1. **회로 동작 > 배선 미관**
   - 동작하는 것이 최우선
   - 시간 부족 시 측정부터

2. **부분 점수 챙기기**
   - 일부만 완성해도 점수
   - 포기하지 말고 끝까지

3. **안전 점수**
   - 전기 안전 수칙
   - 작업장 정리
   - 공구 정리

### 연습 방법
1. **실제 부품으로 연습**
   - 브레드보드 구매
   - 기본 부품 세트 구매
   - 기출 회로 반복 제작

2. **측정 기기 연습**
   - 멀티미터 사용법
   - 오실로스코프 (가능하면)
   - 함수발생기 (가능하면)

3. **시간 제한 연습**
   - 4시간 내 완성 연습
   - 각 단계별 시간 체크
