# 전자기기기능사 기출 회로 모음

## 📌 자주 나오는 회로 Top 10

### 1. 브리지 정류 회로 + 평활 회로

#### 회로 구성
```
AC 입력 → 브리지 정류기 → 평활 커패시터 → DC 출력
                ↓
          부하 저항

부품:
- 브리지 정류기 (또는 다이오드 4개)
- 전해 커패시터 1000μF
- 부하 저항
```

#### 제작 순서
```
1. 브리지 정류기 배치
   - AC 입력 (~, ~)
   - DC 출력 (+, -)

2. 평활 커패시터 연결
   - +극 → DC+
   - -극 → GND

3. 부하 저항 연결

4. 측정
   - AC 입력 전압
   - DC 출력 전압
   - 리플 전압 (오실로스코프)
```

#### 주의사항
```
- 커패시터 극성 확인!
- 브리지 +/- 확인
- 리플 측정 시 AC 모드
```

### 2. 제너 다이오드 전압 안정화 회로

#### 회로 구성
```
입력 → 직렬 저항 → 출력
              ↓
         제너 다이오드
              ↓
             GND

부품:
- 제너 다이오드 (5.1V or 6.2V)
- 직렬 저항 (수백Ω)
- 부하 저항
```

#### 제작 순서
```
1. 직렬 저항 배치
2. 제너 다이오드 연결
   - 캐소드(띠) → 출력
   - 애노드 → GND
3. 부하 저항 연결
4. 측정
   - 입력 전압 변화
   - 출력 전압 일정 확인
```

### 3. 이미터 접지 증폭기

#### 회로 구성
```
Vcc
 ↓
Rc ← 출력
 ↓
 C ──┐
     │ Rb
 B ──┤
     │
입력  │ Re
 ↓   ↓
 ~~~  CE
     │
    GND

부품:
- NPN 트랜지스터 (2SC1815)
- Rc (1~10kΩ)
- Rb (수십~수백kΩ)
- Re (수백Ω~1kΩ)
- CE (10~100μF, 바이패스 커패시터)
- 결합 커패시터 (1~10μF)
```

#### 제작 순서
```
1. 트랜지스터 배치 (E-B-C 확인)
2. 바이어스 저항 연결
3. 바이패스 커패시터 연결
4. 입출력 결합 커패시터
5. 측정
   - Vce (바이어스 전압)
   - 증폭도 (Vout/Vin)
   - 파형 (위상 반전 확인)
```

### 4. Op-Amp 반전 증폭기

#### 회로 구성
```
      Rf
  ┌────────┐
  │        │
입력─Ri─┬─(-)  \
        │     >─ 출력
    ┌──(+)  /
    │   └──┘
   GND

부품:
- Op-Amp (741, LM358)
- Ri (입력 저항, 10kΩ)
- Rf (피드백 저항, 100kΩ)
- 전원 커패시터 (0.1μF)
```

#### 제작 순서
```
1. IC 핀 배치 확인 (점/홈 = 1번)
2. 전원 연결 (±12V or +12V/GND)
3. 비반전 입력 (+) → GND
4. Ri 연결 (입력 → 반전 입력)
5. Rf 연결 (출력 → 반전 입력)
6. 측정
   - 증폭도 = -Rf/Ri
   - 위상 반전 확인
```

### 5. 555 타이머 무안정 멀티바이브레이터

#### 회로 구성
```
Vcc─┬─Ra─┬─Rb─┐
    │    │    │
    8    7    6,2
    555      C
    4    3    │
    │    │   GND
   Vcc  출력

부품:
- 555 IC
- Ra, Rb (kΩ~MΩ)
- C (μF~mF)
- LED + 저항
```

#### 제작 순서
```
1. IC 핀 확인
2. 전원 연결 (8=Vcc, 1=GND)
3. 리셋 핀 (4) → Vcc
4. Ra, Rb, C 연결
5. 6-2번 연결 (트리거-임계값)
6. 측정
   - 주파수 계산
   - LED 깜빡임 확인
```

### 6. LED 점멸 회로 (타이머)

#### 회로 구성
```
Vcc → 555 타이머 → LED + 저항 → GND
       ↓
     RC 회로

부품:
- 555 IC
- 저항 (10kΩ, 100kΩ)
- 커패시터 (10μF)
- LED + 저항 (330Ω)
```

### 7. 전파 정류 회로 (센터탭)

#### 회로 구성
```
AC ──┬─ 다이오드1 ─┬─ 출력
     │            │
센터탭─GND         C
     │            │
     └─ 다이오드2 ─┘

부품:
- 센터탭 변압기
- 다이오드 2개
- 평활 커패시터
```

### 8. 윈 브리지 발진기 (Op-Amp)

#### 회로 구성
```
RC 네트워크 + Op-Amp

부품:
- Op-Amp
- R1, R2 (같은 값)
- C1, C2 (같은 값)
- 피드백 저항

주파수: f = 1/(2πRC)
```

### 9. 논리 게이트 조합 회로

#### 회로 구성
```
입력 A ──┐
         AND ── 출력
입력 B ──┘

부품:
- 7408 (AND 게이트)
- LED + 저항
- 스위치 (입력)
- 풀업/풀다운 저항
```

#### 제작 순서
```
1. IC 핀 확인
2. 전원 연결 (Vcc, GND)
3. 입력 스위치 + 풀업저항
4. 출력 LED + 저항
5. 진리표 확인
```

### 10. 7-세그먼트 디스플레이 구동

#### 회로 구성
```
디코더(7447) → 7-세그먼트

부품:
- 7447 (BCD to 7-seg 디코더)
- 7-세그먼트 (공통 애노드/캐소드)
- 전류 제한 저항 (7개)
- BCD 입력 스위치
```

#### 제작 순서
```
1. 디코더 IC 배치
2. 7-세그먼트 연결
   - a, b, c, d, e, f, g 핀
   - 각 세그먼트마다 저항
3. BCD 입력 (A, B, C, D)
4. 공통 단자 (Vcc or GND)
5. 0~9 숫자 표시 확인
```

## ⚠️ 공통 주의사항

### 회로 구성 전
1. 회로도 정확히 이해
2. 부품 리스트 확인
3. 부품 값 확인 (컬러 코드)
4. 극성 부품 표시

### 회로 구성 중
1. 전원선 먼저 (Vcc, GND)
2. IC는 나중에 (정전기)
3. 극성 확인 (커패시터, 다이오드, LED)
4. 배선은 짧고 정확하게

### 동작 확인 전
1. 육안 검사
2. 단락 확인 (멀티미터)
3. 전원 극성 재확인
4. IC 삽입 확인

### 측정 시
1. 전원 천천히 올리기
2. 전류 확인 (과전류 주의)
3. 발열 확인
4. 동작 확인
5. 측정값 기록

## 💡 실전 팁

### 시간 단축
1. 전원선은 빨강/검정 구분
2. 부품 미리 다리 구부리기
3. 자주 쓰는 배선 길이 미리 준비
4. 부품 배치 먼저, 배선은 나중에

### 점수 올리기
1. 깔끔한 배선 (직각, 정돈)
2. 부품 배치 일정하게
3. 배선 색상 구분
4. 테스트 포인트 표시

### 실수 방지
1. 회로도 옆에 두고 작업
2. 연결할 때마다 체크
3. IC 핀 번호 재확인
4. 극성 부품 두 번 확인
