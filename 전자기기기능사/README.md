# 전자기기기능사 자격증 학습 가이드

## 📋 시험 개요

### 필기 시험
- **시험 시간**: 60분
- **과목 수**: 3과목
- **문항 수**: 60문항 (과목당 20문항)
- **문제 유형**: 객관식 4지선다형
- **합격 기준**: 60점 이상 (100점 만점)

### 실기 시험
- **시험 시간**: 약 4시간 정도
- **문제 유형**: 작업형 (회로 제작 및 측정)
- **합격 기준**: 60점 이상 (100점 만점)

## 📚 필기 과목 구성

### 1과목: 전자 이론
- 전기 기초 이론
- 직류 회로
- 교류 회로
- 전자 회로 이론
- 디지털 회로

### 2과목: 전자 기기
- 증폭 회로
- 발진 회로
- 전원 회로
- 디지털 논리 회로
- 연산 증폭기
- 마이크로프로세서

### 3과목: 전자 부품
- 수동 소자 (저항, 커패시터, 인덕터)
- 능동 소자 (다이오드, 트랜지스터)
- 반도체 소자
- IC (집적 회로)
- 센서 및 액추에이터

## 📖 학습 계획

### 1단계: 기초 다지기 (3주)
- [ ] 전자 이론 기본 개념 학습
- [ ] 전자 기기 주요 회로 이해
- [ ] 전자 부품 특성 파악
- [ ] 기본 계산 문제 연습

### 2단계: 문제 풀이 (3주)
- [ ] 과목별 기출문제 풀이
- [ ] 오답 노트 작성
- [ ] 취약 부분 집중 학습
- [ ] 계산 문제 반복 연습

### 3단계: 실전 대비 (2주)
- [ ] 전체 모의고사 풀이
- [ ] 시간 배분 연습
- [ ] 최종 정리

## 🎯 실기 준비 전략

### 핵심 학습 영역
1. **회로 제작** - 브레드보드/PCB 배선
2. **부품 식별** - 저항, 커패시터, IC 등
3. **측정 기기 사용** - 오실로스코프, 멀티미터
4. **고장 진단** - 회로 동작 확인 및 문제 해결
5. **안전 수칙** - 전기 안전 및 작업 안전

### 학습 방법
- 실제 부품으로 회로 구성 연습
- 측정 장비 사용법 숙지
- 기출 회로 반복 제작
- 시간 제한 두고 실습

## 💡 학습 팁

### 필기 시험
1. **계산 문제 집중**
   - 옴의 법칙, 키르히호프 법칙
   - 전력 계산
   - 주파수 및 공진 회로 계산

2. **회로 이해**
   - 증폭기 동작 원리
   - 필터 회로
   - 디지털 논리 회로

3. **부품 특성 암기**
   - 저항 컬러 코드
   - 다이오드, 트랜지스터 특성
   - IC 핀 배치

### 실기 시험
1. **부품 식별 능력**
   - 저항 컬러 코드 읽기
   - IC 핀 번호 확인
   - 극성 부품 구분

2. **배선 기술**
   - 깔끔한 배선
   - 접촉 불량 방지
   - 단락 주의

3. **측정 기기**
   - 멀티미터 사용법
   - 오실로스코프 파형 확인
   - 함수발생기 설정
